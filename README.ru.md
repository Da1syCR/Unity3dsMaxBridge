# Unity3dsMaxBridge

Редактирование геометрии статических prefab Unity в 3ds Max с возвратом в исходные FBX, сохранением ссылок Unity и назначений материалов.

**Публичная beta · Windows · MIT** · [English](README.md)

## Установка

### Через Git

1. В Unity открой **Window → Package Manager**.
2. Нажми **+ → Install package from git URL** и вставь:

   ```text
   https://github.com/Da1syCR/Unity3dsMaxBridge.git#v0.2.0-beta.2
   ```

3. Дождись установки пакета и зависимости FBX Exporter.
4. Открой **Tools → Unity3dsMaxBridge → Open**.

Для этого способа Git должен быть установлен и доступен в PATH. [Инструкция Unity](https://docs.unity3d.com/6000.0/Documentation/Manual/upm-ui-giturl.html).

### Без Git

Скачай [ZIP исходников](https://github.com/Da1syCR/Unity3dsMaxBridge/archive/refs/tags/v0.2.0-beta.2.zip), распакуй в постоянную папку и выбери **Package Manager → + → Install package from disk → package.json**. Не удаляй распакованную папку, пока пакет установлен.

Используй один способ установки. Если ранее плагин копировался в Assets, убери прежнюю копию перед установкой UPM-пакета.

## Подключение Max

1. В окне Unity нажми **Подключить** или **Настройки → Подготовить подключение Max**.
2. Unity покажет созданный `Connect_Max.ms` и скопирует его путь в буфер обмена.
3. В Max выбери **Scripting → Run Script**, вставь этот путь и выполни скрипт.

Max добавит кнопку **Unity Bridge**. Она повторно открывает окно без создания второй сессии. Команду из категории **Unity3dsMaxBridge** можно назначить на свою панель или горячую клавишу. После перезапуска Max сохранённая команда загружает последнее подготовленное подключение.

Указывать пути к программам, запускать их от администратора, устанавливать MCP или Python для работы плагина не нужно. Импорт добавляется в текущую сцену Max, не сбрасывая и не сохраняя её. Во время синхронизации держи окно моста Max открытым.

## Работа

1. Перетащи сохранённый prefab или его экземпляр в поле **Префаб**. Для отдельной версии общих моделей сначала нажми **Независимая копия**.
2. Нажми **Отправить префаб**.
3. Измени геометрию в Max и нажми **Update now**. Для экспорта по Ctrl+S включи **Update Unity on Ctrl+S** — изначально эта опция выключена.
4. Unity проверит геометрию и автоматически применит её, если это включено. Несохранённый Prefab Mode или Play Mode откладывают применение.

Перетаскивай существующие Unity-материалы в поле **Материалы** по одному или группой. Они автоматически отправляются, когда Max открыл нужную сессию; иначе остаются в очереди. Назначай их через **Unity materials** в Max. Дубли пропускаются.

Переключатель **English / Русский** в шапке окна Unity запоминает выбранный язык. Интерфейс Max остаётся английским.

## Геометрия и материалы

### Перед следующим обновлением

В Max блок **Next update** автоматически обновляется при добавлении и привязке мешей:

- **NEW FBX in ...** — Unity создаст отдельный FBX в указанной папке проекта.
- **ADD TO ...** — меш привязан к существующей модели и предназначен для её исходного FBX. Перед записью Unity проверяет сохранность ссылок. Чтобы создать отдельный FBX, убери эту связь.

Список показывает новые меши, а не каждую правку геометрии. Окончательные уникальные имена файлов выбирает Unity. При редактировании защищённых не-FBX мешей Unity также может появиться дополнительный companion FBX. Если метаданные недоступны, окно попросит обновить пакет и отправить prefab повторно, не угадывая путь назначения.

- Изменения существующей геометрии записываются в исходный FBX. Они видны и другим prefab, использующим эту модель.
- Новый самостоятельный меш Max получает отдельный FBX рядом с первой моделью либо рядом с prefab.
- **Select and Link** позволяет добавить дочерний меш в FBX модели. Если меняются Unity fileID существующих объектов, операция отклоняется с восстановлением файлов. Убери связь нового меша и экспортируй его отдельно.
- **Attach** изменяет существующий меш. Undo в Max с последующим **Update now** позволяет вернуть прежнюю геометрию.
- Назначения материалов сохраняют ссылки на Unity assets. Произвольные шейдеры Max и правки их параметров не превращаются в Unity-материалы.
- Незарегистрированные и пустые material ID остаются отдельными submesh с пустыми слотами материалов.

## Совместимость и ограничения

Проверенная конфигурация разработки: **Unity 6000.0.48f1, 3ds Max 2024, Windows**. Другие версии пока не подтверждены. Пакет требует Unity 6 и FBX Exporter 5.1.3; Autodesk FBX SDK устанавливается как зависимость. При первом скачивании зависимостей Unity нужен интернет.

Beta поддерживает статическую геометрию **MeshFilter + MeshRenderer**. Skinning, blend shapes и удаление исходных мешей не поддерживаются. Разные правки экземпляров одного общего меша не могут стать разной геометрией одного Unity asset. Примитивы Unity и не-FBX меши изначально защищены в Max; их редактирование может создать дополнительный FBX.

Изменения вне плагина могут потребовать повторной отправки prefab. В проекте Unity одна активная сессия, в экземпляре Max — одно активное подключение проекта. Перед сменой проекта подготовь и выполни его Connect_Max.ms, затем отправь префаб.

## Копии и диагностика

Открой **Диагностика и файлы → Открыть папку сессии / Открыть журнал Unity / Скопировать диагностику**. Обмен и резервные копии хранятся в локальных данных текущего пользователя Windows, в `Unity3dsMaxBridge/<ключ проекта>`, вне Unity-проекта. Временная запись моделей использует скрытую папку `.Unity3dsMaxBridgeTemp` рядом с моделью и не требует доступа к корню диска.

При неудачной проверке исходных файлов выполняется откат. Копии сохраняются, но в beta ещё нет браузера резервных копий и кнопки восстановления. Для проверки используй проект с контролем версий или резервной копией.

Если Max не отвечает, открой окно моста, закрой блокирующие диалоги или заново выполни подготовленный скрипт. После обновления Unity-пакета подготовь новый Connect_Max.ms и выполни его перед новой сессией. Незавершённые правки Max сохрани отдельно перед повторной отправкой prefab.

## Обновление и удаление

Установи Git URL с новым тегом либо замени распакованную ZIP-папку и обнови Unity. После этого подготовь и выполни новый скрипт Max. Для удаления Unity-части используй Package Manager.

В Max закрой окно моста и убери кнопку или назначенную команду. Сохранённый макрос — `Unity3dsMaxBridge-Unity3dsMaxBridge.mcr` в папке usermacros Max, настройка подключения — `Unity3dsMaxBridge.ini` в пользовательской папке scripts. Перезапуск Max удаляет активные callbacks. Сохрани резервные копии обмена, пока они нужны.
